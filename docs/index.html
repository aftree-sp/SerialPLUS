一切调试场景，一个工具搞定

从简单的串口收发到复杂的协议分析、自动化测试，SerialPLUS 都已内置。

🔌

串口连接

全参数配置，一键刷新端口列表，连接状态实时指示。

  • 波特率 110 ~ 921600
  • 数据位 / 停止位 / 校验位全支持
  • 硬件 / 软件流控可选
  • RX / TX 字节数实时统计
📟

终端收发

文本与 HEX 双模式显示，支持时间戳与自动滚动。

  • 文本 / HEX 双模式随时切换
  • HEX 发送自动校验格式
  • 时间戳记录每帧到达时间
  • 一键清除接收区
📑

多标签页

每个标签页独立串口连接，真正意义上的多串口并发操作。

  • Ctrl+T 新建 / Ctrl+W 关闭
  • 标签显示端口号 + 连接状态
  • 关闭最后一个标签自动新建
🔧

宏命令

预设常用指令，双击即发，告别重复输入。

  • HEX / 文本两种格式
  • 可视化增删改管理
  • 自动发送 — 最小间隔 10ms
  • 可设定发送总次数
📈

实时波形图

接收到数字数据时自动绘图，支持 1~8 通道同时显示。

  • 逗号 / 空格 / Tab 分隔符
  • 采样窗口大小可调
  • 鼠标悬停显示精确数值
  • 波形实时滚动刷新
🔬

协议解析

内置 Modbus RTU 解析，并支持自定义帧格式。

  • 功能码 / 寄存器地址 / 数据域自动解析
  • 帧构建器 — 可视化拼接发送
  • 解析结果高亮显示
📜

脚本自动化

支持 Python / Lua 脚本，实现复杂自动化测试流程。

  • 脚本内可调用串口收发 API
  • 外部进程调用支持
  • 运行 / 停止一键控制
📋

数据记录

带时间戳的完整收发日志，支持 HEX 格式保存。

  • 保存为 .log 文件
  • HEX 格式记录方便协议分析
  • 开始 / 停止一键切换

快速开始

三步上手

下载安装包，双击运行，即刻连接串口。

1

下载并安装

点击下方按钮下载 Windows 安装包，运行后按提示完成安装（约 30 秒）。

2

选择端口并连接

启动 SerialPLUS 后，在左侧面板选择端口号和波特率，点击「连接」按钮，状态栏变绿即表示连接成功。

3

开始收发数据

在底部输入框输入内容，按 Enter 发送。 需要多路调试时，按 Ctrl+T 新建标签页，每个标签独立连接不同串口。
